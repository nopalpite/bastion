Détermine quelles machines seront proposées au lancement (seules celles de cet OS) — écrivez la commande en conséquence (bash pour Linux, cmd/PowerShell selon le serveur SSH installé côté Windows).

Envoyée telle quelle via SSH (exec_command, pas de terminal interactif) à chaque machine du pool choisi au lancement.

sudo (Linux) : si la commande commence par sudo, le mot de passe SSH lui est fourni automatiquement (comme pour les actions redémarrer/éteindre) — inutile de le retaper. Un sudo plus loin dans la commande (après un &&) n'est en revanche pas détecté : pour chaîner plusieurs commandes nécessitant sudo, utilisez un seul sudo en tête avec un sous-shell, par exemple sudo sh -c "apt update && apt upgrade -y".
